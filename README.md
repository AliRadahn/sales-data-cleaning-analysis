
# Sales Data Cleaning & Analysis

## Project Overview
This project focuses on cleaning, standardizing, and analyzing a sales dataset containing 60 order records using Google Sheets.

## Objectives
- Identify and fix data inconsistencies.
- Standardize dates and customer names.
- Handle missing values.
- Check for duplicate orders.
- Analyze sales performance.
- Create visual reports and summaries.

## Tools Used
- Google Sheets
- Spreadsheet Formulas
- Data Visualization

## Data Cleaning Process

### 1. Date Standardization
Converted inconsistent date formats into a consistent format.

### 2. Customer Name Standardization
Cleaned customer names by correcting inconsistent capitalization and formatting.

### 3. Missing Values
Identified missing payment status information without inventing missing data.

### 4. Duplicate Detection
Checked order IDs for duplicate records.

### 5. Payment Status Standardization
Standardized payment statuses using TRIM and PROPER functions.

### 6. Data Validation
Checked record counts, unique order IDs, missing values, and sales totals.
